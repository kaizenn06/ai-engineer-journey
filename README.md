# AI Engineer Journey

Mình là sinh viên năm 3 ngành Công nghệ thông tin, đang tự học từ nền tảng để trở thành **AI Engineer / ML Engineer**.

Repository này lưu lại bài tập, ghi chú và các dự án trong quá trình học tập của mình, bắt đầu từ **09/10/2026**.

**Mục tiêu:** Chuẩn bị kiến thức và portfolio để ứng tuyển thực tập AI/ML Engineer trước kỳ thực tập tốt nghiệp.

Mình duy trì học tập và cập nhật repository thường xuyên để theo dõi quá trình tiến bộ của bản thân.

## Learning Principles

- Hiểu bản chất trước khi chuyển sang kiến thức nâng cao.
- Kết hợp lý thuyết với thực hành và xây dựng dự án.
- Sử dụng Git để quản lý phiên bản và theo dõi tiến độ.
- Cập nhật repository thường xuyên theo quá trình học thực tế.
